REF STRUCTURE GUIDE

What each step does

Letter / syllable

Chooses one random entry from the group you select and adds it.

Random group

Chooses a non-empty group at random, then adds one of its entries.

Two chosen groups

Randomly chooses between the two groups you select, then adds one of that group's entries.

Space

Adds a space at this point in the name.

Caps

Changes the previous letter or syllable to uppercase.

Parrot 1

Repeats the previous letter or syllable.

Parrot 2

Repeats the whole name assembled so far.

Inverted parrot 1

Repeats the previous letter or syllable backwards.

Inverted parrot 2

Repeats the whole name assembled so far backwards.

Coin flip

Gives the preceding structure a 50% chance to apply.

Type based

Applies the preceding structure only when the generated type matches one or more types you select.

Repeat start

Adds the first letter or syllable in the name again.

Repeat end

Adds the latest letter or syllable in the name again.

Cutout

Removes one random non-space character from the name.

Cutout previous 1

Removes the last character of the previous letter or syllable.

Cutout previous 2

Removes the first character of the previous letter or syllable.

Cutout last 1

Removes the last character of the last letter or syllable.

Cutout last 2

Removes the first character of the last letter or syllable.

Cutout start 1

Removes the last character of the first letter or syllable.

Cutout start 2

Removes the first character of the first letter or syllable.

Reposition 1

Moves the last character of the previous letter or syllable to a random spot in the name.

Reposition 2

Moves a random non-space character to a random spot in the name.
